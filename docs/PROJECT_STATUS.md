## 尚未完成的上线条件

- 正式短信/推送供应商账号、模板审核和回执处理。
- MQTT 生产凭据轮换、ACL、设备证书/密钥生命周期、下行发布和高可用 Broker。
- 后端和数据库尚未迁移到长期运行环境；仍需进程守护、WAF、监控告警和备份恢复演练。
- 多实例场景下基于 Redis 或网关的共享登录限流。
- WebSocket/SSE 实时推送；当前前端每 3 秒轮询刷新。
- 面向生产的自动数据库迁移工具；当前使用初始 schema 与兼容性字段补充。
- MQTT 入站重投幂等；当前订阅器为每次接收生成时间戳消息 ID，只有 HTTP 调用方复用 `messageId` 的重试能可靠去重。
- 问答跨服务告警类型仍使用不一致的中文标签/英文枚举，模糊追问可能误判上下文；当前后端知识回退还会把固定 `100 ppm` 阈值误述为任意正整数。设备接口和告警规则仍强制 `100 ppm`，修复前不能以该问答文案为配置依据。

## 前端协作边界

- 主前端可直接对接系统、设备、3D 地图、告警、隐患闭环、通知、广播和问答接口。
- 主前端先通过 `/api/auth/me` 同步最新身份，再按 `/api/auth/workspace` 返回的模块过滤前端本地导航顺序；仅在开发模式向管理员开放模拟告警，后端权限校验仍是最终边界。
- 用户管理已集成到主前端且仅 `SYSTEM_ADMIN` 可见；已有 `/admin/index.html` 页面保留为本地调试和应急备用入口。
- 当前登录信息保存在同源 `localStorage` 的 `smart-smoke.token` 和 `smart-smoke.user` 中，因此同一浏览器普通窗口的多个页签共享一个账号，后登录会覆盖前一个账号。需要同时验收两个账号时，应使用普通窗口与无痕窗口、不同浏览器或不同浏览器配置文件。
- 前端应把 `401` 统一视为会话失效，把 `403` 展示为权限不足，并使用后端 `message` 显示业务错误。
- 前端不得声称 SMS、MQTT 设备广播或视觉 AI 已成功，除非对应外部适配器已经接入并返回成功状态；钉钉单聊广播以钉钉接口返回结果更新状态。
