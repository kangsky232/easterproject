# 功能完成状态

更新日期：2026-08-27。

本文件用于区分“后端已实现”“本地模拟可验收”和“仍需外部服务”的功能，避免前后端或部署人员把占位能力当成生产能力。

| 模块 | 当前能力 |
| --- | --- |
| 登录与权限 | JWT 登录、当前用户、本人改密、角色授权、登录限流；密码修改/重置/账号禁用后旧 JWT 立即失效 |
| 用户管理 | 用户分页、详情、新增、修改、启停、重置密码、删除；保护当前账号和最后一个启用的系统管理员 |
| 用户管理入口 | 后端独立页面 `/admin/`；主监控前端不包含用户管理视图 |
| 设备管理 | 分页筛选、详情、绑定、编辑、阈值、软解绑、设备令牌创建与轮换 |
| 数据接入 | HTTP 心跳与遥测、华为云 IoTDA MQTT 入站、消息幂等；支持烟雾浓度、环境温湿度、电流、线缆温度、CO 值和蜂鸣器状态；数值保留两位小数 |
| 实时趋势 | 默认展示最近 120 条原始点，每 10 秒刷新；支持 24 小时、7 天和 30 天聚合视图 |
| 系统能力 | 按运行 Profile 返回开发/生产模式，并实时探测 RAG 知识库连接状态和当前模型信息 |
| 告警处置 | 告警查询、确认、解决、误报标记和规则辅助复核；已处置/误报复核使用历史语义 |
| 通知查询 | 通知分页筛选、详情和通道/状态统计 |
| 广播管理 | 广播指令创建、查询、再次下发和删除；配置钉钉后可通过机器人单聊下发给所有已绑定员工，并记录成功/失败状态 |
| 智能问答 | 本地知识检索后通过 Ollama 调用 `gpt-oss:120b-cloud`；提供结构化安全处置卡片、领域限制和分层回退，详见 [优化记录](SMART_QA_OPTIMIZATION.md) |
| 接口文档 | 静态 API 文档、前端契约文档和开发环境 Swagger |
| 数据库升级 | 新 schema 使用 `DECIMAL(12,2)` 存储数值遥测；已有数据库提供浓度小数和扩展传感器字段升级脚本 |

## 模拟实现或占位能力

| 模块 | 当前行为 | 生产接入要求 |
| --- | --- | --- |
| APP 通知 | 告警生成后写入本地通知中心并标记 `SENT` | 接入真实移动推送 SDK 后由适配器投递 |
| SMS 通知 | 告警生成待发送记录，状态为 `PENDING`，不会实际发送短信 | 接入短信供应商、模板、签名、回执和失败重试 |
| MQTT 广播 | MQTT 入站遥测已实现；广播仍只保存指令和状态，不保证已发布到真实设备 | 定义下行主题并实现发布、设备回执、重试和状态同步 |
| 告警视觉复核 | 基于告警类型、浓度和阈值生成规则结论 | 接入摄像头、图像存储和模型推理服务 |

## 尚未完成的上线条件

- 正式短信/推送供应商账号、模板审核和回执处理。
- MQTT 生产凭据轮换、ACL、设备证书/密钥生命周期、下行发布和高可用 Broker。
- 正式域名、TLS 证书、防火墙/WAF、监控告警和备份恢复演练。
- 多实例场景下基于 Redis 或网关的共享登录限流。
- WebSocket/SSE 实时推送；当前前端每 10 秒轮询刷新。
- 面向生产的自动数据库迁移工具；当前使用初始 schema 与兼容性字段补充。

## 前端协作边界

- 主前端可直接对接系统、设备、告警、通知、广播和问答接口。
- 主前端按角色隐藏设备管理、告警处置、广播创建入口，并只在开发模式向管理员开放模拟告警；后端权限校验仍是最终边界。
- 用户管理如需集成到新前端，仅 `SYSTEM_ADMIN` 可访问相关 API；已有 `/admin/` 页面可用于临时管理。
- 前端应把 `401` 统一视为会话失效，把 `403` 展示为权限不足，并使用后端 `message` 显示业务错误。
- 前端不得声称 SMS、MQTT 设备广播或视觉 AI 已成功，除非对应外部适配器已经接入并返回成功状态；钉钉单聊广播以钉钉接口返回结果更新状态。
